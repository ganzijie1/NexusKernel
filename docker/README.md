# Container operations

All roles use the same image. `NEXUSKERNEL_RUNTIME_ROLE=api` starts FastAPI;
`worker` starts the Kernel worker process. Real `.env.*` files are local-only and
are generated by `scripts/init_project.sh` from the tracked examples.

```bash
docker build -f docker/Dockerfile -t nexuskernel-starter:local .
docker compose -f docker/docker-compose-dev.yml up --build api
docker compose -f docker/docker-compose-dev.yml --profile worker up worker
docker compose -f docker/docker-compose-dev.yml --profile infra up mongo redis
```

Pre-production and production Compose files consume an explicitly supplied
`NEXUSKERNEL_IMAGE`. They do not build, push, deploy, create external networks,
or assign fixed addresses.
